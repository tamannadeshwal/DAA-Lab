# AlgoMetrics: Computational Benchmarking Tool

An interactive execution environment designed to analyze runtime growth curves and stack memory footprints across core data structures and looping paradigms.

## Setup Protocols
1. Formulate isolated sandbox environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Windows: venv\Scripts\activate
   ```
2. Provision system requirements:
   ```bash
   pip install -r requirements.txt
   ```
3. Initialize the visual runtime layout:
   ```bash
   streamlit run app.py
   ```
